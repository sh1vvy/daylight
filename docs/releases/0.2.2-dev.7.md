# Daylight 0.2.2-dev.7

A little more Daylight 🦋

This development update brings together the changes tested across eight internal canaries since Dev.6.

- Refreshed Home with sharper branding, compact sign-in and less clutter.
- Quick picks now blends recent listening with discoveries.
- Added **Play my mix**: one tap for a continuing mix of saved music and recommendations, available after sign-in.
- Added **Recommendation languages** in Appearance to hide selected languages from recommendations. Saved music and search remain available; filtering uses known language metadata.
- Reworked Library with a four-cover playlist preview, **Liked songs**, better placement for Spotify import and a simpler Replay shortcut.
- Added playlist name/cover editing and fullscreen artwork viewing.
- Added **More by the artist** and **Similar Albums for you** to albums, plus featured artist profiles to playlists.
- Refined playlist/album opening animations, restored the artwork blur and improved transitions throughout the app. Regular navigation retains its own selection animation with Liquid Glass off.
- Added smoother synced lyric motion and disabled KuGou/BetterLyrics Portato by default; both remain available to enable manually.
- Added a fixed **2×2 record player widget** with artwork and playback controls.
- Added Last.fm browser sign-in, now playing and scrobbling. Listeners connect their accounts without creating developer API keys.
- Improved search speed with bounded request caching, rounded search controls and a profile menu that follows the app theme.
- Removed podcasts, WebDAV, SMB, JioSaavn and the legacy mesh gradient.

**Install:** Download `daylight-dev.apk` and install over Daylight Dev or Canary without uninstalling. Package and signing key are unchanged; Android version code 27 is newer than Canary 8. Installed canaries require this manual update; public Dev builds can use the in-app update prompt.

Stable **0.2.1** remains unchanged. Lossless remains opt-in, with the existing Wi-Fi quality choices.

**Validation:** 1,418 app/shared tests passed; one optional live lyrics check was skipped. The final canary also passed nine native Android checks covering cover transitions, Home quick picks/mix, the keyboard-aware language picker and discovery-row navigation. Real-account recommendations and Last.fm authorization/scrobbling still need phone testing.
